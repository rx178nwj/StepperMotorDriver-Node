# ファームウェア要求仕様書 — NEMA23 ステッピングモータドライバ

| 項目 | 内容 |
|---|---|
| 対象基板 | SteppingMotorDriver_NEMA23（`schematic/schematic.kicad_sch` 2026-10-11 版） |
| MCU | STM32L433CCU6（UFQFPN48、Flash 256KB / SRAM 64KB）＝回路図参照 IC2 |
| モータドライバ | TB67S249FTG＝回路図参照 IC1 |
| 版 | 0.3（2026-10-17：上位通信を差動 I2C（PCA9615）から CAN（TJA1441AT）へ変更） |

**0.3 での変更**：上位通信を CAN に変更する。PCA9615 と I2C2 を削除し、CAN トランシーバ TJA1441AT を追加する。CAN1 を PB8/PB9 に割り当て、それまで PB8/PB9 にあった DRV_AGC0/1 は PB10/PB11 へ移す。バス終端 120Ω は DIP スイッチで切り替える。レジスタマップ（3.8 節）は変えず、転送方式だけを CAN フレームに置き換える。**回路図への反映は未実施**（本書のピン割り当ては変更後の計画値）。

**0.2 での変更**：VREF の分圧抵抗 R32 を未実装とし DAC 出力をそのまま VREF とする。対象モータは 3A 品。TH1 は Murata NCP18XH103F03RB。モータ設定を不揮発保存し、外部通信で設定できるようにする（3.7 節）。

ピン割り当て・周辺定数は、上記回路図から KiCad 10 でネットリストを出力して確認した。設計メモ `schematic/stm32l433_tb67s249_connection.md` の参照番号は再アノテーション前のため、本書では **現在の回路図の参照番号** を用いる。

---

## 1. 目的と範囲

1 枚の基板で 1 台のバイポーラステッピングモータ（NEMA23 想定）を駆動する。上位マスターから CAN バス（トランシーバ TJA1441AT）経由で最大 8 台を制御する。

| フェーズ | 内容 |
|---|---|
| **P1 基本機能（本版で実装）** | クロック・GPIO 初期化、ドライバ制御（励磁・分割・電流）、台形加減速パルス生成、電源/温度監視、異常検出と保護、DIP アドレス、CAN 通信、LED、ローカルジョグスイッチ、ウォッチドッグ、**モータ設定の不揮発保存と通信による設定** |
| P2 拡張 | USB CDC（設定・デバッグ）、AGC（脱調防止）の運用、エンコーダ/原点入力（J10）、センサ I2C（J9、AS5600 等）、ブートローダ連携 |

## 3. 機能要求

### 3.1 起動・システム（P1）

| ID | 要求 |
|---|---|
| FR-SYS-01 | システムクロックは HSI16 → PLL で 80 MHz とする（HSE/LSE は使用しない。PH0/PH1/PC14/PC15 を GPIO として使うため） |
| FR-SYS-02 | リセット直後、ドライバを安全状態にする：EN=Low、DMODE=000（スタンバイ）、RESET=Low、AGC=00、CLK=Low、DAC 出力 0 |
| FR-SYS-03 | 起動時に ADC キャリブレーションを行う |
| FR-SYS-04 | 独立ウォッチドッグ（IWDG）をタイムアウト約 500 ms で動作させ、メインループで更新する |
| FR-SYS-05 | 起動時に DIP スイッチ（ADDR0〜2）を読み、`ID = ADDR0 + 2·ADDR1 + 4·ADDR2` を確定する。動作中の変更は再起動まで反映しない |

### 3.2 ドライバ制御（P1）

| ID | 要求 |
|---|---|
| FR-DRV-01 | ステップ分割を 1, 2, 4, 8, 16, 32 から選択できる。DMODE への対応は下表（データシート表「DMODE のファンクション」）。1/2 は (a) 型を使用する |
| FR-DRV-02 | スタンバイ解除（DMODE≠000）後、7.5 µs 以上待ってから他の信号を変化させる（FW では 20 µs 以上待つ） |
| FR-DRV-03 | モータ電流は mA 単位で指定し、DAC コードへ換算する：`V_DAC = VREF = I/1.25`、`code = V_DAC / VDDA × 4095`。VDDA は VREFINT で補正する |
| FR-DRV-04 | 電流設定の範囲は 250〜3000 mA。上限 3000 mA は対象モータ定格と J3（JST XH、AWG22 で 3A）の定格に合わせる。範囲外の設定値は受け付けない |
| FR-DRV-05 | 電流 0 は DAC 下限（バッファ有効時 約 0.2V = 250 mA 相当）で実現できないため、励磁 OFF は EN=Low で行う |
| FR-DRV-05a | R32 がないため DAC を停止すると VREF が浮く。DAC は初期化後停止せず、不要時は最小出力（コード 0）にする |
| FR-DRV-06 | 停止後、設定時間（既定 500 ms）経過したら保持電流へ切り替える。動作開始時は運転電流へ戻してから最初のパルスを出す |
| FR-DRV-07 | AGC0/AGC1 は P1 では Low 固定（AGC 無効）。動作中に AGC0 を切り替えない（データシート注意） |
| FR-DRV-08 | 電気角初期化コマンドで RESET を 10 µs High にする（停止中のみ） |
| FR-DRV-09 | MO（初期電気角で Low）の状態をステータスとして公開する |

DMODE 対応表（データシートの列順は DMODE0, DMODE1, DMODE2）：

| 分割 | DMODE0 | DMODE1 | DMODE2 |
|---|---|---|---|
| スタンバイ | L | L | L |
| 1/1 | L | L | H |
| 1/2 (a) | L | H | L |
| 1/4 | L | H | H |
| 1/2 (b) | H | L | L |
| 1/8 | H | L | H |
| 1/16 | H | H | L |
| 1/32 | H | H | H |

### 3.3 パルス生成・動作制御（P1）

| ID | 要求 |
|---|---|
| FR-MOT-01 | TIM1_CH1 のハードウェア PWM で CLK を生成する。パルス幅 High ≥ 1 µs、Low ≥ 1 µs（データシート最小 500 ns） |
| FR-MOT-02 | ステップ速度範囲：1〜100,000 step/s（マイクロステップ単位）。TB67S249 の入力上限 1 MHz に対して CPU 負荷で制限する |
| FR-MOT-03 | 台形加減速：開始速度 v0、最高速度 vmax、加速度 a、減速度 d（step/s²）で 1 ステップごとに速度を更新する（`v² ← v² ± 2a`） |
| FR-MOT-04 | 位置決めモード：絶対目標位置・相対移動量を指定し、減速距離 `v²/2d` を見込んで目標で停止する |
| FR-MOT-05 | 速度モード：符号付き目標速度で連続回転する。速度変更は加減速を伴う |
| FR-MOT-06 | 逆方向への指令は、一度減速停止してから DIR を切り替えて再始動する。DIR の変更はパルス停止中のみ行う |
| FR-MOT-07 | 減速停止（STOP）と即時停止（ESTOP：パルス即停止）を持つ |
| FR-MOT-08 | 位置は符号付き 32bit のステップ数で保持し、パルス出力ごとに更新する。停止中に現在位置を任意値に再定義できる |
| FR-MOT-09 | 回転方向の論理反転を設定できる |
| FR-MOT-10 | 分割設定の変更は停止中のみ受け付ける（位置の単位が変わるため） |

### 3.4 監視・保護（P1）

| ID | 要求 |
|---|---|
| FR-MON-01 | VM を 10 ms 周期で計測する：`VM = code/4095 × VDDA × 19`。サンプル時間は 247.5 サイクル |
| FR-MON-02 | VM 正常範囲は 10.5〜28.0 V（ヒステリシス 0.5 V）。入力定格 12〜24 V、TB67S249 下限 10 V、AP63205 推奨上限 32 V に基づく |
| FR-MON-03 | VM が正常範囲で 50 ms 以上安定するまで、ドライバをスタンバイから解除しない（USB 給電のみでは VM≈0V となり励磁しない） |
| FR-MON-04 | 励磁中に VM が範囲外になったら、パルスを即停止し EN=Low として異常（低電圧 / 過電圧）をラッチする |
| FR-MON-05 | LO1/LO2 の立ち下がりを EXTI で検出し、パルス即停止・EN=Low にして異常をラッチする。異常種別は下表。VM 不在時やスタンバイ中の LO 入力は無視する |
| FR-MON-06 | 基板温度（TH1）を β 式（R25 = 10kΩ、B = 3434K）で計測する。80 °C 以上で過熱異常、70 °C 以上で警告。ADC 値が両端付近（断線・短絡）なら無効値とし保護判定しない |
| FR-MON-07 | MCU 内部温度を計測しステータスに公開する（保護には使わない） |
| FR-MON-08 | 異常解除コマンドで、DMODE を一度スタンバイにしてドライバのラッチを解除する。原因が残っている場合は解除しない |
| FR-MON-09 | 通信タイムアウト（設定値 ms、0=無効）を超えて自局宛ての CAN 要求フレーム（3.8 節）を受信しない場合、動作中なら減速停止する |

LO1/LO2 の意味（データシート）：

| LO1 | LO2 | 状態 |
|---|---|---|
| H | H | 正常 |
| H | L | 負荷オープン（OPD） |
| L | H | 過電流（ISD） |
| L | L | 過熱（TSD） |

### 3.5 状態遷移（P1）

```text
          ┌──────────┐ VM正常50ms ┌──────────┐ ENABLE ┌──────────┐
 起動 ──▶ │  NO_VM   │──────────▶│ DISABLED │──────▶│ ENABLED  │◀─┐
          │EN=L,STBY │◀──────────│ EN=L     │◀──────│ EN=H     │  │停止
          └──────────┘ VM範囲外   └──────────┘DISABLE└────┬─────┘  │
                ▲                                         │移動    │
                │CLEAR_FAULT(原因解消時)                    ▼        │
          ┌──────────┐◀── LO1/LO2・励磁中のVM異常・過熱 ──┌──────────┐ │
          │  FAULT   │◀────────────────────────────────│ (MOVING) │─┘
          │EN=L,STBY │                                  └──────────┘
          └──────────┘
```

- MOVING は ENABLED 中のサブ状態（パルス出力中）としてステータスビットで表す。
- 移動コマンドは ENABLED でのみ受け付ける。

### 3.6 表示・操作（P1）

| ID | 要求 |
|---|---|
| FR-UI-01 | LED_MCU：1 Hz で点滅（ハートビート） |
| FR-UI-02 | LED_RUN：ENABLED で点灯、MOVING で 5 Hz 点滅、それ以外消灯 |
| FR-UI-03 | LED_FAULT：FAULT 時に異常コード回数の点滅を繰り返す（1=OPD、2=ISD、3=TSD、4=低電圧、5=過電圧、6=基板過熱）。過熱警告時は点灯 |
| FR-UI-04 | LED_COMM：自局宛て（0x100+ID）またはブロードキャストのフレームを受信するたびに 50 ms 点灯。CAN がエラーパッシブまたはバスオフの間は 2 Hz で点滅 |
| FR-UI-05 | SWITCH1/SWITCH2（20 ms デバウンス）：ローカルジョグ有効時、押している間 CW/CCW にジョグ速度で回転する。ジョグ有効は設定フラグ（既定 有効） |
| FR-UI-06 | SWITCH1+SWITCH2 同時 2 秒長押しで、DISABLED⇔ENABLED を切り替える。FAULT 中は異常解除を行う |

### 3.7 設定の不揮発保存（P1）

接続するモータの種類によって適切な設定が異なるため、モータ設定を不揮発メモリに保存し、外部通信（3.8 節）で読み書き・保存できるようにする。

| ID | 要求 |
|---|---|
| FR-NV-01 | 保存対象：運転電流、保持電流、分割、FLAGS（方向反転・ジョグ）、通信タイムアウト、最高速度、加速度、減速度、開始速度、ジョグ速度、保持移行時間、1 回転のフルステップ数（レジスタ 0x20〜0x3F） |
| FR-NV-02 | STM32L433 には EEPROM がなく、基板にも外付け EEPROM がないため、内蔵 Flash の末尾 2 ページ（0x0803F000〜0x0803FFFF、各 2KB）を EEPROM の代わりに使う。この領域はリンカでプログラム領域から除外する |
| FR-NV-03 | 64 バイトのレコード（識別子・版・連番・設定・CRC32）を追記し、ページが満杯になったらもう一方のページを消去して書く。起動時は CRC が正しい最新連番のレコードを読む |
| FR-NV-04 | 電源断対策：レコードは本体を先に書き、識別子を含む先頭 8 バイトを最後に書く。新しいレコードが完成するまで前のレコードを消さない。書き込み途中の領域を読んだときの ECC エラー（NMI）は無効レコードとして扱う |
| FR-NV-05 | 起動時、保存設定があれば読み込み、なければ工場出荷値を使う。読み込んだ値が範囲外なら丸めて CONFIG_STATUS で知らせる |
| FR-NV-06 | 外部通信で設定レジスタを書くと RAM 上の設定に即時反映し「未保存」とする。SAVE で保存、LOAD で保存値に戻す、FACTORY で工場出荷値に戻す（RAM のみ。保存は SAVE） |
| FR-NV-07 | Flash 消去中は CPU が最大約 25 ms 止まるため、SAVE・LOAD・FACTORY はモータ停止中のみ受け付ける（励磁したままの停止は可） |
| FR-NV-08 | 工場出荷値の電流は運転 1000 mA / 保持 500 mA とする。未知のモータを接続しても過電流にならない値とし、3A モータでは設定してから SAVE して使う |

### 3.8 通信（P1：CAN1）

| ID | 要求 |
|---|---|
| FR-COM-01 | CAN1（bxCAN）を CAN 2.0A（標準 11bit ID）で動作させる。CAN FD は使わない（STM32L433 の bxCAN は非対応。TJA1441AT は FD 対応だがクラシック CAN として使う） |
| FR-COM-02 | ビットレート 500 kbit/s（暫定、U-1）。サンプルポイント 87.5% 付近。ファームウェアの定数で 125k / 250k / 1M にも変えられること |
| FR-COM-03 | CAN ID の割り当て（`ID` = DIP 値 0〜7、起動時に読む）：<br>`0x000` ブロードキャスト指令（上位→全台）<br>`0x080 + ID` 異常通知（基板→上位）<br>`0x100 + ID` 要求（上位→基板）<br>`0x180 + ID` 応答（基板→上位） |
| FR-COM-04 | 受信フィルタで `0x000` と `0x100 + ID` だけを受け付ける。それ以外のフレームは無視する（応答しない） |
| FR-COM-05 | 書き込み要求：`[0x01][REG][DATA 1〜6 B]`（DLC 3〜8）。DATA を REG から連続するレジスタへ書く。応答 `[0x81][REG][CMD_RESULT]`（DLC 3） |
| FR-COM-06 | 読み出し要求：`[0x02][REG][LEN]`（DLC 3、LEN 1〜6）。応答 `[0x82][REG][DATA LEN B]`（DLC 2+LEN）。1 フレーム分はスナップショットで返し、値の途中更新による破損を防ぐ |
| FR-COM-07 | 不正な要求（未定義の OP、DLC 不一致、LEN 範囲外）には `[0xFF][REG][2]` を返す |
| FR-COM-08 | 多バイト値はリトルエンディアン。32bit レジスタは 4 バイト全てを 1 フレームで書いた場合だけ反映する（部分書き込みは反映せず CMD_RESULT=2） |
| FR-COM-09 | ブロードキャスト指令：`[COMMAND]`（DLC 1）。受け付けるのは 2 DISABLE、3 STOP、4 ESTOP だけで、応答は返さない。それ以外の値は無視する |
| FR-COM-10 | 異常通知：STATE が FAULT へ遷移したとき `0x080 + ID` で `[STATE][FAULT]`（DLC 2）を 1 回送信する |
| FR-COM-11 | 応答は要求の受信から 2 ms 以内に送信キューへ入れる |
| FR-COM-12 | バスオフからは自動復帰（ABOM 有効）、送信は自動再送（NART 無効）。エラーパッシブ・バスオフは LED_COMM で表示する（FR-UI-04） |
| FR-COM-13 | トランシーバの S ピンは回路で GND に直結する（常時ノーマルモード）。ファームウェアからサイレントモードには切り替えない（H-8） |

- 0x20〜0x3E（RW）は範囲外の値を書くと反映せず CMD_RESULT=2。開始速度・ジョグ速度が最高速度を超える場合は、使用時に最高速度へ制限する。分割の変更は停止中のみ。
- 1 フレームの書き込みに複数レジスタを含めた場合（例：0x24 MICROSTEP と 0x25 FLAGS）、アドレス昇順で反映する。
- 1 フレームの書き込み・読み出しは最大 6 バイト。読み出しでマップ外のバイトは 0xFF を返す。
- 32bit の移動指令（0x40〜0x4C）と COMMAND（0x50）は別フレームで送る。
- 0x40〜0x50 は読み出すと 0 を返す。

## 6. 試験項目（P1）

1. 電源投入時、EN/DMODE/DAC が安全状態であること（ロジアナ・テスタ）。手順：[test_poweron_safe_state.md](test_poweron_safe_state.md)
2. USB 給電のみで NO_VM を維持し、励磁しないこと。
3. VM 12 V / 24 V で VM_MV が ±2% 以内であること。
4. DMODE 各設定で 1 回転のステップ数が一致すること。
5. CLK 波形：パルス幅 ≥ 1 µs、速度 1〜100k step/s、加減速プロファイル。
6. DAC 電流設定：MOTVREF_TP1 の電圧が `I/1.25` に一致すること。
7. モータ線外し（OPD）で FAULT へ遷移し、CLEAR_FAULT で復帰すること。
8. 励磁中に VM を遮断して FAULT（低電圧）になること。
9. CAN：ID 0x100+ID で全レジスタ読み書き、32bit 書き込みの部分書き込みが無視されること。他局宛てのフレームに応答しないこと。ブロードキャスト ESTOP で全台が停止すること。
9a. CAN 終端：両端の 2 台だけ終端 ON のとき CANH–CANL 間が約 60Ω であること。終端の有無でエラーカウンタと波形を比較すること。
9b. CAN バスオフ：CANH–CANL を短絡して解除すると自動復帰し、LED_COMM の表示が正しいこと。
10. 通信タイムアウトで減速停止すること。
11. ウォッチドッグ：メインループ停止でリセットし、安全状態で再起動すること。
12. 設定保存：RUN_CURRENT=3000 などを書いて SAVE → 電源再投入後も保持され、CONFIG_STATUS bit0=1 であること。
13. 保存の繰り返し：65 回以上 SAVE してページ切り替えを跨いでも最新値が読めること。
14. 保存中の電源断：SAVE 直後に電源を切っても、次回起動時に前回値か新しい値のどちらかで起動すること。
15. 範囲外の書き込み（RUN_CURRENT=3500 など）が CMD_RESULT=2 で拒否されること。
16. 3A 設定で MOTVREF_TP1 が約 2.40V になること。3A 連続運転時の IC・TH1 温度を測定すること。
