## 定義済みサイズ欄に使用する一覧

- 配線幅: 0.15, 0.20, 0.25, 0.50, 2.00。
- ビア（外径 / 穴径）: 0.60 / 0.30, 0.80 / 0.40, 1.00 / 0.50。
- 差動ペア（線幅 / 間隔 / ビア間隔）: PCA9615 = 0.15 / 0.15 / 0.15、USB = 0.25 / 0.15 / 0.15。間隔は暫定、ビア間隔は銅箔外周間の距離。

## CANバスの差動配線（2026-10-17 予定）

CANの公称特性インピーダンスは120 Ω（ISO 11898-2。終端120 Ωと同じ）。基板内の配線は短いので、インピーダンスより次の配置を優先する。0.15 mm幅/0.15 mm間隔の差動インピーダンスは積層決定後に計算する。

- CANH/CANLを対として並走させ、J1–J2間を一直線のバス（基板内の分岐なし）とし、TJA1441ATへの分岐は最短（数mm以内）にする。
- ESD保護（TVS）はJ1/J2の近くに置き、コネクタ→TVS→トランシーバの順で配線する。
- 終端（120 Ω＋DIP SW1の4極目）はTJA1441ATのピン6/7の近くに置く。
- TJA1441ATのVCC/VIOのデカップリング（各100 nF）はピン3/5の直近に置き、GNDはIn1.CuのGND面へ短いビアで落とす。
- CANH/CANLはVM・BUCK_SW・モーター相出力から離し、直下のIn1.CuのGND面を分断しない。

## PCA9615DPの差動配線（旧仕様。PCA9615削除により廃止予定）

NXPの推奨する公称差動線路インピーダンスは100 Ω。出典: https://cache.nxp.com/docs/en/data-sheet/PCA9615.pdf （Rev.2、p.2、差動バスおよび終端の説明）。0.15 mm幅/0.15 mm間隔が100 Ωとなることはまだ確認していない。

- SDAペア: U2 DSDAP pin8 → DI2C_SDA_P、DSDAM pin9 → DI2C_SDA_M。
- SCLペア: U2 DSCLP pin7 → DI2C_SCL_P、DSCLM pin6 → DI2C_SCL_M。
- MCU側のSDA/SCLはシングルエンドであり、Defaultの0.15 mmを使用する。
- SDAとSCLをそれぞれ対として近接・並走させる。ペア同士は可能なら0.5 mm以上離す。
- F.Cu配線の直下に連続したIn1.CuのGND面を設ける方針。面の分断・VM/SW/モーター出力の近傍を避ける。GND面の作成は今回未実施。
- コネクタ間のバス経路とU2への分岐を短くし、スター配線を避ける。各ペアで層変更・ビア数を揃える。
- 既存回路のR13/R15/R16/R18は600/DNP、R14/R17は120/DNPと確認。抵抗値と実装指定は変更していない。数珠つなぎの物理的両端だけ終端を実装するという既存仕様に従う。
- 現在の_P/_M名は維持。KiCad差動ルータでペア認識されない場合はネット名の整合した変更が必要になるため、実配線開始前に確認する。

JLCPCBの発注積層（外層銅厚、F.Cu–In1.Cuの絶縁厚、誘電率）が決まった後、PCA9615の100 ΩとUSBの90 Ωを計算する。USB幅0.25 mmを固定したまま実現できる間隔・積層を選ぶ。暫定間隔を製造用インピーダンス確定値として扱わない。

## 電流・検証状況

4層 F.Cu / In1.Cu / In2.Cu / B.Cu、板厚1.6 mmを確認。最小配線幅・銅箔クリアランス0.15 mm。
電源幅0.50 mmは指定値。VM/GNDPWRの10 A級という既存設計前提に対する連続電流容量を保証しない。銅箔面・並列ビア・銅厚・温度上昇の検討が必要。モーター相出力2.00 mmも電流容量の確定値ではない。
既存4本のGNDPWRの0.20 mm配線はIC2のパッド付近の配線として維持し、自動拡幅していない。ネットクラスの変更は既存配線の幅を自動変更しない。
設定変更後DRC: 違反129件、未接続316件（変更前と同数）。今回の作業はサイズ設定であり、実配線・内層銅箔面・製造データ完成は未実施。
